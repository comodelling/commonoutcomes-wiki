# Welcome to CommonOutcomes' wiki

This wiki provides some context, advice and directions for the [CommonOutcomes platform](https://commonoutcomes.org).<br>
It also serves as a working reference for the project, and will thus co-evolve both with the platform and its parent software project, [CommonGraph](https://github.com/comodelling/commongraph).

!!! warning "beta testing"
    We are currently looking for volunteers to beta test CommonOutcomes.
    If you are interested, please [contact us](mailto:contact@comodelling.org).
    Until the end of this phase, the platform will be accessible only to logged-in users.

Beyond the different ways to collaborate we suggest in [this section](collaborating.md), we warmly welcome any additional feedback or questions you may have [via email](mailto:contact@comodelling.org).
