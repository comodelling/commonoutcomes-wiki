Exploring

CommonOutcomes makes it possible to search and explore changes that have been entered by co-modellers.

Search

You can use a search bar to look for changes using natural language. This will return changes that match any part of a change's title. In addition, you can filter any properties by including property_name:value within your search query.

Search results appear simultaneously as a list, a graph and a histogram of support ratings. These three panes are interactive, meaning that elements can be clicked to select a specific change or to filter further.

Element-focused view

When selecting a graph element, whether node or edge, you can view its properties, ratings (if any), and connections. The info pane also contains edit and history tab for further interactions with the element. The flow view offers a quick glance at the element's connections, the ability to change the layout, create new nodes and connections, and download the subgraph data locally.
